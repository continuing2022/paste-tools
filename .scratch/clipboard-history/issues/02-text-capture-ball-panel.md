# 02 — 纯文本捕获 → 悬浮球 → 历史面板浏览

**What to build:** 应用在后台持续监听系统剪贴板；用户复制纯文本后自动出现一条剪贴板条目（忽略空/空白；连续相同则刷新为最新；满 20 条 FIFO 丢最旧；跨重启保留）。桌面常驻悬浮球，点击可切换历史面板开/关；面板按新旧顺序展示文本预览，历史为空时有明确空状态。

**Blocked by:** 01 — 脚手架、技术选型 ADR 与 ClipboardHistory 测试 seam

**Status:** ready-for-agent

- [ ] 复制纯文本后，剪贴板历史中出现对应剪贴板条目
- [ ] 空字符串或纯空白文本不产生条目；连续与最新相同的内容刷新为最新而不另建条目
- [ ] 满 20 条后再捕获新内容时丢弃最旧条目；重启应用后历史仍在
- [ ] 点击悬浮球可打开/关闭历史面板；面板新条目在前，文本可预览；空历史有空状态
