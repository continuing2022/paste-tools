# 04 — 回贴与辅助功能权限指引

**What to build:** 用户在历史面板点选一条剪贴板条目执行回贴：先写回系统剪贴板，再触发粘贴，完成后关闭历史面板。写回引发的剪贴板变化走同一套连续去重，不另建条目。若自动粘贴因缺少辅助功能权限失败，应用给出清晰指引，而非静默失败。

**Blocked by:** 02 — 纯文本捕获 → 悬浮球 → 历史面板浏览

**Status:** ready-for-agent

- [ ] 点选条目后内容写回系统剪贴板并触发一次粘贴
- [ ] 回贴完成后历史面板自动关闭
- [ ] 回贴写回不会新增历史条数（连续去重刷新为最新）
- [ ] 缺少辅助功能权限时有明确指引，而非无反馈失败
