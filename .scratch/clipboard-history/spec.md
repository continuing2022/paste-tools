## Problem Statement

Mac 用户在日常复制文本与图片时，系统剪贴板只保留「当前最新一份」。一旦再次复制，先前内容就丢失，只能反复切换窗口重新复制。用户需要一份本机、轻量、可快速唤出的剪贴板历史，以便回顾并再次使用最近复制过的纯文本与图片。

## Solution

提供一个 Mac 桌面应用：**Paste Tools（剪贴板历史）**。应用在系统剪贴板内容变化时捕获 **剪贴板条目**，持久保存在本机 **剪贴板历史**（最多 20 条）。用户可通过常驻 **悬浮球** 或同一全局快捷键切换打开/关闭 **历史面板**，从中浏览条目、执行 **回贴**、**删除条目** 或 **清空历史**。

领域用语以仓库根目录 `CONTEXT.md` 为准。

## User Stories

1. As a Mac 用户, I want 在复制纯文本后自动出现一条剪贴板条目, so that 我之后还能找回这段文字
2. As a Mac 用户, I want 在复制图片后自动出现一条剪贴板条目, so that 我之后还能找回这张图
3. As a Mac 用户, I want 复制文件等非纯文本非图片内容时不被记录, so that 历史里不会塞满无用项
4. As a Mac 用户, I want 空字符串或纯空白文本不被记录, so that 20 个名额不被浪费
5. As a Mac 用户, I want 同一次剪贴板变化同时含纯文本与图片时只记图片, so that 一次复制对应一条清晰历史
6. As a Mac 用户, I want 连续复制与最新条目相同的内容时不另建条目而是刷新为最新, so that 误触复制不会占满名额且排序仍反映「刚刚又复制了它」
7. As a Mac 用户, I want 历史最多保留 20 条且满员时 FIFO 丢弃最旧, so that 本地占用可控且始终偏向最近内容
8. As a Mac 用户, I want 退出并重启应用后仍能看到之前的剪贴板历史, so that 昨天复制的内容今天还能用
9. As a Mac 用户, I want 桌面上有一个可拖拽的悬浮球, so that 我能随时看到入口并打开历史面板
10. As a Mac 用户, I want 点击悬浮球可切换历史面板开/关, so that 不靠快捷键也能操作
11. As a Mac 用户, I want 用同一个全局快捷键切换历史面板开/关, so that 键盘流下能快速唤出或收起
12. As a Mac 用户, I want 在历史面板中看到最近的剪贴板条目列表（新的在前）, so that 我能挑选要用的内容
13. As a Mac 用户, I want 文本条目以纯文本展示预览, so that 我能辨认内容
14. As a Mac 用户, I want 图片条目显示缩略图或可辨认预览, so that 我能辨认是哪张图
15. As a Mac 用户, I want 点选一条条目执行回贴（写回系统剪贴板并自动粘贴）, so that 我能立刻把内容贴进当前应用
16. As a Mac 用户, I want 回贴完成后历史面板自动关闭, so that 我能回到原应用继续工作而不被面板挡住
17. As a Mac 用户, I want 回贴写回剪贴板时不额外新增一条历史（按连续去重刷新为最新）, so that 回贴不会污染历史容量
18. As a Mac 用户, I want 能删除单条剪贴板条目, so that 我可以去掉敏感或无用的个别记录
19. As a Mac 用户, I want 能一键清空历史, so that 我可以快速抹掉全部本地历史
20. As a Mac 用户, I want 删除条目或清空历史时不影响系统剪贴板当前内容, so that 我正在用的复制内容不会被悄悄清掉
21. As a Mac 用户, I want 文本只保存纯文本不保留富文本格式, so that 行为简单、跨应用粘贴可预期
22. As a Mac 用户, I want 应用在后台持续监听剪贴板变化, so that 即使面板关闭也会记录
23. As a Mac 用户, I want 历史为空时面板给出明确空状态, so that 我知道还没有可回贴的内容
24. As a Mac 用户, I want 拖动悬浮球到合适位置, so that 它不遮挡我的工作区
25. As a Mac 用户, I want 首次需要辅助功能等权限时得到清晰指引, so that 回贴（自动粘贴）能够生效
26. As a Mac 用户, I want 关闭历史面板的路径除回贴外还包括快捷键再次切换与点击悬浮球, so that 我不必完成回贴也能收起面板
27. As a Mac 用户, I want 满 20 条后再复制新内容时自动丢掉最旧一条, so that 我不必手动腾位置也能继续记录
28. As a Mac 用户, I want 在面板中按时间/新旧顺序浏览, so that 「最新」心智与 FIFO、连续去重刷新一致

## Implementation Decisions

- **Greenfield Mac 桌面应用**：仓库目前仅有领域文档与 agent 配置；本 spec 交付完整可运行的最小产品（MVP）。
- **技术选型未在 grilling 中锁定**：实现方可选用原生 Swift/SwiftUI（或 AppKit）优先；若选用跨平台壳，仍须满足 macOS 剪贴板监听、全局快捷键、悬浮球与辅助功能粘贴。选型若构成难逆决策，应另写 ADR。
- **单一测试 seam：`ClipboardHistory`（剪贴板历史）**：所有捕获规则、容量、去重、删除/清空、持久化读写的行为测试落在此模块；不把 AppKit/权限/快捷键/UI 作为该 seam 的单测对象。
- **剪贴板观测适配层**：将系统剪贴板变化标准化为「纯文本 | 图片 | 可忽略」观测，再交给 `ClipboardHistory`；图文并存时适配层或 History 入口统一执行「图片优先、只取一种」。
- **回贴编排**：UI/应用服务负责「取条目内容 → 写回系统剪贴板 → 触发粘贴 → 关闭历史面板」；写回引发的再观测必须进入同一套连续去重路径。
- **持久化**：剪贴板历史跨重启保留；存储介质任选（如 Application Support 下的文件/SQLite），但对 `ClipboardHistory` 通过端口抽象，使 seam 可测。
- **容量常量**：最大条目数 = 20；FIFO 丢弃最旧。
- **文本模型**：仅存纯文本；不存 RTF/HTML。
- **图片模型**：存可回贴的图片数据（具体编码实现自定）；面板需可预览。
- **悬浮球**：常驻、可拖拽；点击切换历史面板。
- **快捷键**：单一全局快捷键切换历史面板（具体默认键位实现自定，应可在系统中注册且尽量不与常见快捷键冲突）。
- **删除/清空**：只修改剪贴板历史，永不清除或覆盖系统剪贴板（除非用户主动回贴写回）。
- **权限**：自动粘贴可能需要辅助功能（Accessibility）权限；应用应在失败时提示用户，而不是静默失败且无反馈。
- **词汇**：实现、测试、issue 标题一律使用 `CONTEXT.md` 中的术语（剪贴板条目、剪贴板历史、悬浮球、历史面板、回贴、删除条目、清空历史）。

## Testing Decisions

- **好测试的标准**：只断言对外行为（给定剪贴板观测与命令后，历史中的条目集合/顺序/内容如何变化），不断言私有结构、存储文件格式细节或 UI 控件树。
- **测试模块**：`ClipboardHistory`（唯一自动化 seam）。覆盖至少：纯文本捕获、图片捕获、忽略非文本非图、忽略空/空白、图文并存取图、连续去重并刷新为最新、第 21 条挤掉最旧、删除条目、清空历史、持久化往返后内容一致、回贴写回再观测不新增条数。
- **非 seam / 手工或薄集成**：悬浮球与面板交互、全局快捷键切换、回贴的系统粘贴、权限弹窗——本 MVP 以手工验收为主；无代码库 prior art（greenfield）。

## Out of Scope

- 富文本 / HTML / RTF 保留
- 文件、文件夹或其他私有剪贴板类型的历史
- 全局去重（非连续相同也合并）
- 按使用频率淘汰
- 搜索、收藏、置顶、分组、云同步、多设备
- 历史加密保险箱 / 密码管理器级保密模式
- 开机自启（可作为后续增强，本 spec 不要求）
- 隐藏/关闭悬浮球的长期设置（本 spec 要求应用运行期间球常驻）
- 自定义快捷键设置 UI（若实现默认键即可；设置页非必须）
- Windows / Linux
- 浏览器扩展形态
